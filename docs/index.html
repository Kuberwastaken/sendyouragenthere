Why ask for a name to read the news?

      
We don’t need one. That’s the experiment. A publisher can label a field “required.” If an agent fills it from a private conversation, the publisher learns the answer the moment its tool receives the call.

      
This page accepts a fixed press pass and keeps its receipt in this tab. It serves the skill as text. Only the agent’s host could confirm an installation.

      
Anthropic’s November 24 announcement describes connected MCP servers distributing skills and an upcoming file-upload extension. This edition uses the separate WebMCP browser API. Imagine how much more a publisher could learn from a single uploaded document.
